# Ast Operations

محتاج انشي برنامج خاص بالشركة لتتبع الموظفين والحضور والانصراف وساعات العمل مع حساب الرواتب والإجازات المدفوعة وغيرها والخصومات وايضاً ارسال الطلبات من المناديب وعند زيارة كل زبون يقوم المندوب بارسال صورة المحل ورقم واسم الزبون سواء لديه طلب أو زيارة فقط وادخال المنتجات من المستودعات وتجهيز الطلبات من المستودعات واسناد الطلبات للسائقين وتسليمها كل الطلبات تكون بكل تفاصيلها لوكيشن الزبون ورقم هاتفه وموعد التسليم كل ذلك يكون بتحديث حالة الطلب وتذكيرات وتتبع للسائق كل ذلك يكون باشعارات صوتية ومرئية باحترافية وبتزامن مع كل الاجهزة يكون كل ذلك احترافي ومميز ودقيق وسريع وارسال تقارير علي الوتساب. البدء بالمرحلة الأولى: دورة الطلبات والميدان والمستودعات والتوصيل (تطبيق المندوب لتسجيل الزيارات وصورة المحل وموقع العميل والطلبات، لوحة المستودع لإدارة المنتجات وتجهيز الطلبات، وإسناد وتتبع الطلبات للسائقين مع الإشعارات الصوتية والمرئية وتحديث الحالات لحظياً).
